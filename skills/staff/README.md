# staff skill

Claude Code skill that teaches the assistant how to use the `staff` CLI and follow repo conventions.

## Install

```bash
staff install staff
```

This symlinks `SKILL.md` into `~/.claude/skills/staff/` so Claude Code loads it automatically.

## What it covers

- Repo layout and project categories
- CLI commands and when to use each
- `staff.json` manifest format
- Naming, structure, and design conventions
